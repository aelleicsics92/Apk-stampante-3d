# Spoolio

App Android per stampa 3D: magazzino bobine (con link ai prodotti), archivio stampe con costi, calcolatore prezzo al volo. Dati sincronizzabili tra dispositivi via Firebase Realtime Database (opzionale).

- **APK**: scheda *Releases*, file `Spoolio.apk` (compilato da GitHub Actions a ogni push).
- **Sviluppo**: `www/` (HTML/CSS/JS puro) + Capacitor. `npx cap sync android`.
- **Cloud**: Impostazioni, Cloud condiviso (guida inclusa nell'app).
